# 🎵 MoodTunes AI - Backend API

FastAPI backend service for MoodTunes AI music recommendation platform.

## Features
- 🎭 Real-time Facial Emotion Detection (DeepFace / OpenCV)
- 🎧 Emotion-driven Music Recommendations (Last.fm, YouTube API & Scraper Failover)
- 💬 AI Chatbot Assistant with Automatic Failover (Groq Llama-3 & Google Gemini 2.0)
- 🎙️ Voice-to-Text Search & Commands (Deepgram SDK)
- 🗄️ MongoDB Cloud Persistence for Playlists, Favorites, and User Sessions

## API Documentation
Once running, the interactive OpenAPI documentation is available at:
- **Swagger UI**: `/docs`
- **ReDoc**: `/redoc`
- **Health Check**: `/health`
